About Federated Learning

How privacy-preserving AI works for medical imaging

What is Federated Learning?

Federated Learning (FL) is a machine learning approach where a model is trained across multiple devices or servers holding local data samples, without exchanging raw data. Each hospital trains the model locally and only shares model weight updates — never patient MRI scans.

Why it matters for medical AI

🔒 Privacy

Patient MRI scans never leave the hospital

🌍 Diversity

Model learns from patients across multiple hospitals

⚡ Efficiency

Only model weights (~44MB) transmitted — not raw images

🏥 Scalable

Scales to hundreds of hospitals without centralizing data

Project Details

Model ResNet-18 (pretrained ImageNet)
FL Framework Flower (flwr) v1.7.0
Strategy FedAvg + FedProx + FedBN
Dataset Brain Tumor MRI — 5600 images, 4 classes
Best Accuracy 93.71% (Round 9)
Deployment Docker + Flask
